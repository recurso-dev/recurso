# Recurso Motion Principles

## Philosophy

Motion communicates state, change, progress, feedback and causality.

It is not decoration.

## Priorities

Use motion for:

- state transitions
- table updates
- drawers
- sheets
- dialogs
- number changes
- status changes
- async operations
- financial workflows

## Signature Recurso moments

### Payment

Pending
→ Processing
→ Succeeded

### Invoice

Draft
→ Finalized
→ Open
→ Paid

### Reconciliation

Difference
→ Processing
→ ₹0
→ RECONCILED

### Ledger

Posting
→ Debit = Credit
→ BALANCED

## Rules

- Prefer subtle transitions.
- Avoid excessive animation.
- Avoid infinite decorative animation.
- Avoid motion that delays interaction.
- Respect prefers-reduced-motion.
- Motion must never obscure financial information.
